# Inventory Web 4

**Aplikasi Manajemen Inventaris Berbasis Web Menggunakan PHP Native dan MySQL**

## Deskripsi
Inventory Web 4 adalah aplikasi berbasis web untuk membantu pengelolaan data inventaris secara lebih mudah, terstruktur, dan efisien. Proyek ini menggunakan PHP Native dan MySQL.

## Fitur
- Login dan logout
- Manajemen produk
- Pencatatan pergerakan barang
- Manajemen pengguna

## Teknologi
- PHP Native
- MySQL
- HTML, CSS, dan JavaScript
- XAMPP
- Git dan GitHub

## Cara Instalasi
1. Jalankan Apache dan MySQL melalui XAMPP.
2. Clone repository: `git clone https://github.com/juliyana02/inventory-web4.git`
3. Buat database melalui phpMyAdmin.
4. Impor file `schema.sql`.
5. Sesuaikan konfigurasi database di `config.php`.
6. Buka `http://localhost/inventory-web4/` di browser.

## Tujuan Proyek
Menerapkan pengembangan aplikasi web menggunakan PHP Native, MySQL, dan GitHub.
